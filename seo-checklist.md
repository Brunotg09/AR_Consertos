# Checklist SEO - AR Consertos

## 1. Google Search Console (URGENTE)
- [ ] Acessar https://search.google.com/search-console
- [ ] Adicionar propriedade: `https://ar-consertos.vercel.app`
- [ ] Verificar propriedade com a meta tag (já adicionada no código)
- [ ] Enviar sitemap: `https://ar-consertos.vercel.app/sitemap.xml`
- [ ] Solicitar indexação nas páginas:
  - [ ] Home: `/`
  - [ ] Serviços: `/servicos`
  - [ ] Inverter: `/inverter`
  - [ ] Produtos: `/produtos`
  - [ ] Contato: `/contato`
