# Sistema de Parcerias - A.R. Consertos

**Para parceiros que desejam se juntar à nossa rede**
**Versão: 1.2 - Atualizado em 10/09/2026**

---

## Como Era Antes

- Parceiros eram empresas (CNPJ)
- Cada parceiro tinha seu próprio catálogo de serviços
- O admin definia uma comissão fixa para cada parceiro
- O admin escolhia manualmente quem iria atender cada serviço
- Não havia sistema de notificações
- Não havia avaliações

---

## Como Funcionará Agora

### Você como Parceiro

- Você é um profissional autônomo (pessoa física)
- O admin cadastra você com seus dados pessoais e CPF
- O admin escolhe as categorias que você atende:
  - Ar Condicionado
  - Geladeira
  - Máquina de Lavar
  - TV/Monitor
  - Outros

---

## Fluxo de Trabalho

### 1. Cadastro

**Onde:** Através do painel do admin

**O que você precisa informar:**
- Nome completo
- CPF
- Email
- Telefone (WhatsApp)
- Foto sua (obrigatória)
- Endereço (rua, número, bairro, cidade, estado, CEP)
- Categorias que você trabalha

---

### 2. Recebendo Serviços

Quando um cliente solicita um serviço na sua categoria, você recebe uma notificação:

```
┌─────────────────────────────────────────────┐
│  Nova Oferta Disponível!                    │
├─────────────────────────────────────────────┤
│  Conserto Ar-Condicionado                   │
│  Cliente: Maria Silva                       │
│  Endereço: Rua das Flores, 123 - Centro    │
│  Data: 10/09/2026, 14:00                    │
│  Valor: R$ 350,00                           │
│  Comissão do admin: 30%                   │
│  Seus ganhos: 70% (R$ 245,00)              │
│  Tempo para aceitar: 24 horas               │
│                                             │
│  [Ver Detalhes]    [Aceitar Serviço]        │
└─────────────────────────────────────────────┘
```

---

### 3. Aceitando o Serviço

**Como funciona:**
- Vários parceiros da mesma categoria recebem a oferta ao mesmo tempo
- **O primeiro a aceitar fica com o serviço**
- Se ninguém aceitar em 24 horas, o serviço volta para o admin

**Para aceitar:**
1. Clique em "Aceitar Serviço"
2. Confirme que deseja atender
3. Pronto! O serviço é seu

---

### 4. Executando o Serviço

**Após aceitar, o fluxo é:**

```
Você aceitou → Vá até o local → Realize o serviço → Conclua
```

**Durante o serviço:**
- Tire fotos **ANTES** do reparo (mínimo 1 foto)
- Tire fotos **DEPOIS** do reparo (mínimo 1 foto)
- Preencha um relatório técnico
- Pegue a assinatura do cliente

---

### 5. Conclusão

Quando você concluir:
- O serviço fica com status "Concluído"
- O admin recebe notificação
- Você recebe seus ganhos conforme combinado

## Seus Ganhos

### Como é calculado

| Exemplo | Valor |
|---------|-------|
| Valor do serviço | R$ 350,00 |
| Comissão do admin (30%) | R$ 105,00 |
| **Seus ganhos (70%)** | **R$ 245,00** |

- A comissão é definida pelo admin quando o serviço é criado
- Você sempre sabe quanto vai ganhar antes de aceitar

### Como recebe o dinheiro

1. **Conecte sua conta do Mercado Pago**
   - Acesse "Configurações" no seu painel
   - Clique em "Conectar com Mercado Pago"
   - Faça login e autorize o acesso

2. **Pagamentos automáticos**
   - Quando o cliente paga, o dinheiro vai direto para sua conta
   - Split automático: empresa recebe a comissão, você recebe o restante
   - Sem necessidade de repasse manual

3. **Métodos de pagamento aceitos**

| Método | Pagamento Parcial? | Como funciona |
|--------|-------------------|---------------|
| 📱 PIX | ✅ SIM | Pague parcelado (ex: R$ 20 agora, R$ 50 depois) |
| 💳 Débito | ✅ SIM | Pague parcelado (ex: R$ 30 agora, R$ 70 depois) |
| 💳 Crédito | ❌ NÃO | Pagamento integral (parcelamento pelo cartão) |

4. **Exemplo de pagamento parcial (PIX)**
   - Serviço: R$ 150,00
   - 1º pagamento: R$ 50,00 (PIX) → Restante: R$ 100,00
   - 2º pagamento: R$ 30,00 (PIX) → Restante: R$ 70,00
   - 3º pagamento: R$ 70,00 (Débito) → Pago! ✅
   - Você recebe sua parte proporcional a cada pagamento

## Perguntas Frequentes

**Q: O cliente sabe que fui eu que fiz o serviço?**
R: Não. Para o cliente, tudo aparece em nome do admin.

**Q: Posso cancelar um serviço que aceitei?**
R: Sim, mas precisa informar o motivo.

**Q: E se ninguém aceitar o serviço?**
R: Após 24 horas, o serviço volta para o admin.

**Q: Como recebo meus pagamentos?**
R: Conecte sua conta do Mercado Pago nas configurações. O pagamento é automático via split.

**Q: Preciso ter conta no Mercado Pago?**
R: Sim, é necessário para receber os pagamentos automaticamente.

**Q: O que é o split?**
R: Quando o cliente paga, o sistema divide automaticamente: a empresa recebe a comissão e você recebe o restante direto na sua conta.

**Q: O cliente pode pagar parcelado?**
R: Sim! PIX e Cartão de Débito permitem pagamento parcial (ex: R$ 20 agora, R$ 50 depois). Cartão de Crédito é pagamento integral.

**Q: E se o cliente pagar apenas parte do serviço?**
R: Não tem problema! O pagamento vai acumulando até completar o valor total. Você recebe sua parte proporcional a cada pagamento.

**Q: Como funciona o pagamento parcial?**
R: Se o serviço custa R$ 150,00 e o cliente paga R$ 50,00 primeiro, você recebe sua proporcional na hora. Depois quando ele pagar mais, você recebe de novo.

**Q: Posso atender várias categorias?**
R: Sim! Você pode atender várias categorias.

**Q: O que acontece se o cliente não pagar?**
R: O serviço fica com pagamento pendente. Você já recebeu pelo menos parte do valor via split.

**Q: Tem prazo para o cliente pagar?**
R: Não há prazo fixo. O cliente pode pagar quando quiser, até completar o valor total.

## Como Funciona o Pagamento

### Passo a Passo

```
PASSO 1: Você conclui o serviço
─────────────────────────────────────────────
- Status: "Concluído"
- Valor fica disponível para pagamento

PASSO 2: Cliente acessa o histórico
─────────────────────────────────────────────
- Vê o serviço concluído
- Clica em "Pagar Agora"

PASSO 3: Cliente escolhe método
─────────────────────────────────────────────
- PIX: Pode pagar parcial (ex: R$ 50 agora)
- Débito: Pode pagar parcial (ex: R$ 30 agora)
- Crédito: Pagamento integral (ex: 3x R$ 50)

PASSO 4: Dinheiro cai na sua conta
─────────────────────────────────────────────
- Split automático via Mercado Pago
- Você recebe sua parte proporcional
- Sem necessidade de repasse manual
```

### Exemplo Prático

```
Serviço: Limpeza de Ar-Condicionado
Valor: R$ 150,00
Sua parte (70%): R$ 105,00

Pagamento 1 (PIX): R$ 50,00
  → Você recebe: R$ 35,00

Pagamento 2 (PIX): R$ 30,00
  → Você recebe: R$ 21,00

Pagamento 3 (Débito): R$ 70,00
  → Você recebe: R$ 49,00

Total recebido: R$ 105,00 ✅
```
